## First Look at Anchorpoint

Anchorpoint is for people who keep assets they own and want one named anchor desk, not mixed untitled project piles. It gives you own assets, a project list, and a short path back to a git view you already keep. It does not replace the rest of your PC. It sits beside the files you already use.

## Inside Anchorpoint

Anchorpoint is a local Windows asset workspace with a named anchor desk, a short project list, and a clear last handoff. It does not try to replace the rest of the PC. It sits beside assets you already keep and holds only the project that is open now.
The layout stays small on purpose: one desk, one list, one path back. Extra piles wait for their own title. Anchorpoint starts with a local profile and does not need a complex account system.

The anchor desk stays on files you already own. Untitled piles stay off the live list.

## Quick Start with Anchorpoint

1. Open the last Anchorpoint session on assets you keep, not a new empty pile.
2. Read the anchor desk and the last handoff.
3. Finish one visible git view inside Anchorpoint.
4. Write what changed, then close with a shorter project list than you found.
5. If the desk feels crowded, drop anything that belongs to a different project.
6. Leave the anchor desk on assets you already own.
